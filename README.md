# macOS Tahoe Launcher — Tahap 1

Build (AndroidIDE terminal): gradle assembleDebug  (Gradle 8.7, AGP 8.5.2, JDK 17, compileSdk 34)
APK: app/build/outputs/apk/debug/app-debug.apk
Pasang lalu tekan Home -> pilih "macOS" -> Always.

Fitur: menu bar + dropdown, widget kalender, Dock (ikon macOS 26), Launchpad (semua app), Spotlight,
Control Center (volume, kecerahan, media, pintasan Wi-Fi/Bluetooth/Fokus).
Tahan lama ikon Dock = pilih aplikasi Android untuk ikon itu. Tahan lama desktop = ganti wallpaper.
